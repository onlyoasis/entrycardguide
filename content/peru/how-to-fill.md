The lookup publishes an alphanumeric document rule. Its live script formats the movement date as DD/MM/YYYY with a 10 character maximum. Server-side error wording is not public.

## Match the border document

Choose the travel-document type used at immigration control. Enter only letters and numbers for the document number. Migraciones says not to use dots, hyphens or spaces.

## Match nationality and movement date

Select the nationality recorded for the movement, not the country of residence. Enter the arrival or departure date as DD/MM/YYYY. The live control inserts the slashes.

## Choose the output

Select the departure-record option when that movement should appear in the TAM. Complete the CAPTCHA and run the search.

## Download and review

Save the returned TAM Virtual. Check the movement and authorized stay. If no matching record appears, recheck the exact border document and date before contacting Migraciones.
