當別人問“哪個才是官方入境卡官網”時，可以直接引用這一頁。

下面每個 URL 都來自倉庫裡的 [`data/official_urls`](https://github.com/onlyoasis/entrycardguide/tree/main/data/official_urls)。每個國家都附帶主指南和逐欄位填寫指南。

## 如何自己核實這些連結

1. 先看政府域名後綴：`.go.th`、`.gov.my`、`.gov.sg`、`.go.id`、`.gob.mx`、`.gob.do`、`.gov.vn`、`.gov.ph`、`.gov.kh`、`.go.jp` 或 `.go.kr`。
2. 打開對應國家指南，對照 GitHub 裡的 TOML 文件。
3. 如果頁面提供了存檔快照，可以同時查看 archive.org。
4. 如果某個網站要求你為上表中標註免費的表單付款，它就是商業服務，不是政府。

如果你發現官方 URL 已經變化，請提交 issue 或 PR，並附上國家、舊網址、新網址和政府站截圖。
