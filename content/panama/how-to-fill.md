The live bilingual form exposes required controls and standard date or email input types. It publishes no regexes, character limits or validation messages, so none are invented here.

## Movement

Choose entry into or exit from the country and select the current customs checkpoint from the live list. An arriving traveller should not leave the declaration set to exit.

## Traveller identity

Copy first names, surnames, nationality, passport number and date of birth from the travel document. The live form requires the email address twice. Use the same spelling in both fields.

## Goods and values

Answer for everything carried by the declared family group. Include regulated food, plants, animals, commercial goods and reportable cash or negotiable instruments when the live question applies.

## Photograph, submit and save

Follow the current photograph step; it replaces a handwritten signature for the digital route. Review the declaration, submit it and save the QR response code immediately. Keep a printed backup if possible.
