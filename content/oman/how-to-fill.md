The public wizard exposes the eligibility questions and the FAQ publishes several document conditions. The actual application is login-gated, so later validation attributes and error text were not readable. This guide does not invent them.

## 1. Check the current exemption

{{< official-link site="oman.visa_exemption" >}}

Find the passport in the current first or second group and read every condition. The 14-day route has no visa form. GCC citizens also need no visa.

## 2. Select passport nationality

Use the nationality printed in the travel document, not the country of residence.

## 3. Answer the GCC-residence question

Answer yes only if you currently hold residence in Bahrain, Kuwait, Qatar, Saudi Arabia or the UAE. Then choose the country shown on the residence permit.

## 4. Use only an offered visa subtype

The result page supplies the eligible products, fee, stay duration and conditions. Choose from that result, not from a blog or another traveller's screenshot.

## 5. Check passport validity

The ROP FAQ says a normal passport should have at least 6 months of validity before entry.

## 6. Prepare the passport file

Keep the file at or below 512 KB and make sure every character remains readable after compression.

## 7. Prepare the picture file

The same 512 KB limit applies to the picture. The public FAQ does not publish a pixel size or regex, so this guide does not claim one.

## 8. Use an email you control

The ROP sends the application copy and payment receipt to the registered email. If approved, the electronic visa also arrives there.

## 9. Apply early enough

Lodge at least 4 days before arrival. The official wording is a recommendation and says processing can vary, so leave extra time.
