## Visit Japan Web 是什麼

Visit Japan Web 是日本官方的入境相關 QR Code 服務，覆蓋可用場景下的入境、海關和免稅手續。

它免費。

穩定的官方來源是日本數字廳 `.go.jp` 服務頁。遇到複製登入頁或在日本政府域名之外索取護照資料的 App，要先停下核對。
