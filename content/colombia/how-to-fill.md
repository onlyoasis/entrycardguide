The current application shows five steps and several visible instructions. It does not expose readable regex, maxlength or validation attributes. Use the live controls and do not assume a format that is not shown.

## 1. Choose the current movement

Select travel to Colombia or travel from Colombia, then the real transport type. Check-Mig handles entry and exit; the selected direction must match this movement.

## 2. Match the itinerary

Choose the Colombian immigration checkpoint and current travel date. The visible date control displays `mm/dd/yyyy`. For an air journey, the field asks for the flight number without letters.

## 3. Copy personal and contact data

Use the valid travel document carried for this movement. Enter current contact details and the actual purpose. A visa, when required, remains separate.

## 4. Add accommodation when applicable

Use the lodging for this trip, not an address from an old registration. Follow the dynamic form if the selected direction or transport changes what is requested.

## 5. Read the current questions

Answer the questions shown for this journey. Review before submission: Migración Colombia says submitted data cannot be edited, so a mistake requires a new registration.

Save the confirmation email or download the record from the official app.
