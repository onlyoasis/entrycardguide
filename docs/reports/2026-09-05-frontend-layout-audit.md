# 全站前端评估与优化验收

日期：2026-09-05。基线：`a279b97`。范围为现有 50 国、中英文全部页面的布局与交互，
不修改国家内容、官方 URL、费用、核验日期或字段规则。

## 结论

已修复共用组件造成的提前换行、窄列、横向溢出与键盘焦点丢失。正文、表格、工具和侧栏
分别按用途分配宽度；没有用整页隐藏溢出来掩盖内容。

| 实测项 | 修改前 | 修改后 |
| --- | --- | --- |
| 原有全站扫描 | 314 页 × 3 视口，942 组合 | 相同集合通过；另补 320px，共 1,256 组合 |
| 整页横向溢出 | 255 组合：390px 为 249，768px 为 6 | 0 |
| 手机校验输入框 | 626 个输入框，390px 最窄 28px | 390px 全部 303px；320px 全部 233px |
| 平板字段说明 | 954 张字段卡，768px 说明列 152–230px | 说明列至少 596px，示例另排 |
| 正文与主区域链接 | 314 页基线 | 全量相同，文本仅忽略布局空白后比较 |
| CSS gzip | 7,989 字节 | 8,570 字节 |
| 决策脚本 gzip | 1,914 字节 | 1,988 字节 |

浏览器枚举的是 `public/` 中实际包含 `main` 的 314 个 HTML 页面，包括两个 404、排除重定向。
Hugo 构建另报告 EN 212 / ZH 210；这不是浏览器扫描的页面计数。

## 发现与修复

- `assets/css/main.css`、`layouts/shortcodes/official-link.html`：官方链接块使用不换行的横向
  Flex、子项受最小内容宽度限制，长政府网址把整页撑宽。改为手机纵排、较宽屏幕横排，徽标
  顶部对齐，网址按实际空间换行。
- `assets/css/main.css`、`layouts/shortcodes/validator.html`：原网格固定占用 180px 标签、80px
  状态和两段间距，手机输入列只剩内边距。改为标签、输入与提示明确分行，输入至少 44px 高、
  字号 16px。工具脱离文章排版规则，错误与帮助说明占完整一行。
- `layouts/_default/how-to-fill.html`：字段示例固定 380px，平板正文被挤成窄列。改为手机单列、
  平板“说明在上、示例在下”、桌面弹性三列；示例不再跟随长说明拉成大片空白。错误解码取消
  固定 180px 代码列，使原话与解释上下对齐。
- `layouts/index.html`：移动国家行的费用抢占国名宽度，变更列表两层固定列把说明挤到边缘。
  费用移到国名下方，变更记录按断点重排；桌面国家网格在 1024px 使用四列，1280px 起五列。
- `assets/css/main.css`、`layouts/_default/`：自定义 Tailwind `maxWidth` 配置没有生成已有
  `max-w-none` 类，部分正文/工具被 Typography 默认宽度约束。恢复该标准工具类，段落等阅读
  内容上限 760px，工具使用所属容器；文章侧栏统一 240px、正文列弹性收缩。
- `layouts/index.html`、各页 Hero：统一响应式标题与上方留白，避免平板字号过大；首页高亮词
  继承标题字体，`one URL` 不再被拆成两块。正文使用现有 ink/rule/muted，移除 Typography 默认
  颜色对既有设计系统的覆盖。
- `layouts/_markup/render-table.html`：两个 Markdown 表格增加独立滚动区域、可见键盘焦点，
  保留原生 table、列标题语义、原单元格及对齐信息。官方目录仍使用独立六列表格。
- `layouts/_default/baseof.html`、`layouts/404.html`：增加中英文跳过导航入口，进入后焦点落到
  `main`；首页搜索组、输入与其他互动元素有可见焦点。
- `assets/js/decide.ts`：独立评审复现切换问题后焦点回到 BODY。选择、返回、重启后聚焦新的
  问题/结果标题，并统一滚动；首次打开不抢焦点，减少动态效果偏好启用时不用平滑滚动。

## 验证

- `npm run build:prod`、`npm run check:seo`、`git diff --check` 通过。
- 全量浏览器扫描：314 页 × 320/390/768/1440px，1,256 组合，整页溢出为 0。
- 314 页主区域文本与链接前后相同；全部 626 个输入、954 张字段卡都有尺寸记录。
- 两语种决策树各 173 个可达状态（44 个问题、129 个结果），全部从真实界面选择路径：
  共 346 个状态、258 个结果路径；每个结果在四种宽度检查，官方按钮 URL 与数据文件一致。
- 校验器实际输入 64 组无效值检查；错误提示可见、与标签不重叠；护照合法值恢复 OK。
- 首页搜索、无结果、展开后续国家、清空，以及 skip-link 键盘进入正文通过。
- 上轮目录 100 次国家搜索、100 行中英内容/链接对比、12 个布局组合、126 个导航组合回归通过。
- 独立只读评审未发现新增阻断问题；另实测 Markdown 表格方向键滚动、skip-link 与焦点。
  其提出的决策焦点问题已修复并补审通过；主控自行验证全部交互，不以评审自报替代测试。
- 5 个回归断言覆盖长链接、输入宽度、字段说明宽度、正文空间和步骤焦点。临时恢复基线源码后
  五项全部失败；逐字节还原修复源码、重新构建后全部通过。

本机完整证据在 `test-results/frontend-audit/`：`before.json`、`accepted.json`、
`interactions-local.json`、`asset-sizes.json`、前后截图及验证脚本。目录被 Git 忽略。

## 边界与后续

- 这是前端布局和交互验收，不能替代官方表单字段规则审查，也不能证明 SEO/转化效果改善。

  项目入口文档中“已自托管字体”的旧描述不代表当前运行事实。
