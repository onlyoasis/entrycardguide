# 盈利模式再分析：读者不是资产，被引用的事实才是

记录时间：2026-07-23
输入：`docs/reports/affiliate-placement-2026-07-23.md`、`docs/reports/gsc-ga-follow-up-2026-07-23.md`、`docs/tasks/04-affiliate-links-revenue-integrity.md`、仓库现状盘点
状态：**分析与建议，未执行**

## 一句话

联盟零转化不是位置错了，是品类错了。本站的产品目标是**让访客 10 秒内离开、去政府网站**，而联盟收入要求**留住访客并制造购买意图**——两者方向相反。同期真正在增长的资产不是读者（462 月活、16 秒、无回访），是**被 AI 助手引用的事实库**（ChatGPT 占 44% 流量）。变现方向应该跟着资产走，从 B2C 注意力转到 B2B 数据。

## 一、先把账算清楚

三种模式在当前规模和 20 倍规模下的量级估算（标注为估算，非预测）。联盟一行沿用 affiliate-placement 报告 3.3 节的算法。

| 模式 | 462 月活（当前） | 10,000 月活（20 倍） | 是否受流量约束 |
|---|---:|---:|---|
| 联盟（SafetyWing + Airalo） | 0.02–0.06 单/月 → **< $1/月** | 0.4–1.3 单/月 → **$5–20/月** | 是，线性 |
| 捐赠 / GitHub Sponsors | ≈ **$1/月** | ≈ **$25/月** | 是，线性 |
| 展示广告 | $1–3/月 | $20–60/月 | 是，且违反 Task 04 |
| **B2B 数据授权** | **$200–2,000/月/客户** | 同左，但更好谈 | **否** |

运行成本这一侧：Cloudflare Pages 免费额度 + 公开仓库的 GitHub Actions 免费 + 域名约 $12/年。**这个站的盈亏平衡线是每年 12 美元。**

两个推论：

1. **B2C 变现在任何可预见的规模下都是零头。** 就算流量翻 20 倍，联盟 + 捐赠加起来不到 $50/月。一个 B2B 客户抵得上现有联盟模式几百年。
2. **没有生存压力，所以不必急着变现。** 该做的是积累别人复制不了的资产，而不是在 462 月活上榨取转化。

## 二、联盟模式为什么结构性不成立

联盟收入 = 停留时长 × 购买意图 × 会话延续。三个乘数在本站都接近 0：

| 乘数 | 实测 | 能不能改 |
|---|---|---|
| 停留时长 | 16 秒（ChatGPT 来源 18 秒） | 不能。核对一个政府域名本来就是秒级动作 |
| 购买意图 | 无。访客在做核验，不在购物 | 不能。意图由入口决定，不由页面决定 |
| 会话延续 | 462 活跃里 460 是新用户 | 很难。一次性需求，填完就不再需要 |

再叠一层：**站点的成功定义是"访客尽快离开去官网"。** 把这条做得越好，联盟表现越差。这不是可以靠调位置化解的矛盾，把卡片挪到首屏也只是把一个不相关的商品塞进一个 10 秒的核验动作里。

affiliate-placement 报告的结论（"当前约束是流量，不是位置"）成立，但可以更进一步：**即使流量解决了，约束也会变成意图。** 联盟模式对这个站永远是三流选项。

## 三、资产盘点

真正积累下来的东西，全部可量化：

| 资产 | 现状 | 别人复制的成本 |
|---|---|---|
| 官方 URL + 主办机构 + `last_verified` + Wayback 快照 | 18 国，`data/official_urls/*.toml` | 中。可抄，但维护要持续投入 |
| **中介/仿冒站证据库**（域名 + DNS 证据 + 首次发现日期） | **37 条** | **高。需要长期观测和 DNS 审计，抄不到"首次发现时间"** |
| 机器可读字段规则（正则、长度上限、日期格式、官方报错文案） | 17 国 / 170 条规则，`data/rules/*.json` | 高。每条都要实际填过表才写得出 |
| 字段填写卡片 | 17 国 / 149 张，`data/fields/*.toml` | 高 |
| 变更日志 | 18 国 / 22 条 | 中 |
| **AI 引用份额** | ChatGPT 贡献 44% 用户；Bing/Copilot 引用基线 0 | 未知，但正在被动积累 |
| 站点本身 | 156 篇内容（78 英 + 78 中）、100 页已索引 | 中 |

`data/` 目录已经是一个 API 的雏形：schema 稳定、构建时强制校验（`scam-site.html` 和 `official-link.html` 找不到条目直接 `errorf` 中断构建）、每条都有日期戳、全部走 git 版本化。这套约束是无意中做出来的最值钱的东西——它让数据**可被第三方审计**，而这正是 B2B 买数据时问的第一个问题。

缺口：Australia 没有 `data/rules/australia.json` 和 `data/fields/australia.toml`（18 国里只有 17 国有字段规则）。

## 四、四条候选路径

### A. 数据授权 / API（唯一与流量脱钩的路）

把 `data/` 暴露成版本化的 JSON 端点 + 定价页。Hugo 已经有 `[outputFormats.LLMS]` 的先例（`layouts/index.llms.txt`），加一个 JSON 输出格式是同样的机制，不需要后端。

谁会买：

| 买家 | 动机 | 真实性判断 |
|---|---|---|
| 企业差旅 / TMC 合规工具 | 不能让员工被中介骗，有合规预算 | **最真实**。无中介分成绑定 |
| 旅行保险公司 / 银行旅行权益 | 出行前提醒是留存动作 | 真实 |
| 反欺诈 / 浏览器安全厂商 | 买的是 37 条中介域名那部分 | 真实，但体量不够 |
| OTA / 机票元搜索 | 订票后提示"你还需要填 X 表" | **不真实，见第六节** |

约束检查：与 Task 04 的 out-of-scope 条款零冲突。数据授权发生在站外，读者看到的页面一个字不改，克制的视觉系统一分不损。这是它相对"把联盟卡片上移"的决定性优势。

### B. 把诈骗域名库贡献出去，换外链和权威背书

37 条带 DNS 证据 + 首次发现日期的记录，本质是一个垂直领域的 threat feed。提交给 PhishTank、APWG、Google Safe Browsing、Netcraft 这类机构。

这不产生直接收入，但它同时打中两个当前最硬的瓶颈：

- **外链 = 0**（两份 GSC 报告连续两个月的同一结论，也是主表页排名 35–89 的根因）。安全机构和研究者的引用是高权重外链，且获取方式是提交证据而不是求人。
- **权威背书**。"我们的诈骗站数据被 X 收录"比"我们自己说这是诈骗站"强一个量级，同时也是 B2B 谈判时的第一张凭证。

成本接近零，风险接近零，与克制原则无冲突。**这是投入产出比最高的一项。**

### C. 补完承诺（收入预期 ≈ 0，做的理由是诚信一致性）

1. **Airalo**——Task 04 从一开始就要求两个伙伴，`airalo_url = ""` 至今未填，两栏网格里只有一张卡。eSIM 对"填完表即将落地要联网"的读者比保险贴合得多。收入预期仍然接近 0，做它是为了让 `about.md` 那句"That's it. That is the entire business model."站得住。
2. **GitHub Sponsors**——仓库没有 `.github/FUNDING.yml`。开源 + 公共品 + 反诈定位与赞助高度契合，转化路径比联盟短（只需要认同，不需要购买意图）。成本 10 分钟，预期 $0–20/月。

### D. 明确排除

| 方向 | 为什么排除 |
|---|---|
| 展示广告（AdSense 等） | Task 04 明令禁止；且 `static/_headers` 的 CSP 严格、`tailwind.config.js` 主动禁用阴影和渐变，加广告等于自毁视觉定位 |
| 给中介发"合规徽章"/认证 | 卖赎罪券。站点存在的前提是不从中介那里拿钱，`about.md` 已公开承诺"never, ever" |
| 付费代办、加急服务 | 直接变成本站正在指控的那类中介 |
| 卖用户数据 | 没有数据可卖——validator 全在浏览器跑，不收集任何输入 |
| 弹窗 / 退出挽留 / 悬浮条 | Task 04 明令禁止，且与 16 秒核验动作正面冲突 |

## 五、两个前置条件

### 5.1 仓库没有 LICENSE 文件

`find . -iname 'license*'` 返回空。但 `content/about.md` 第 26 行写着"100% open source"。

这同时是两件事：

- **一个和联盟位一模一样的信用缺口**——Task 04 当初的论证是"说了有联盟链接却没有，读者会认定整个站是表演性质的"。"说了开源却没有 LICENSE"是同一种失效，而且对开发者读者更刺眼。
- **数据授权路线的硬阻塞**。没有明示许可 = 默认保留全部权利，法律上能卖，但与公开宣称的"开源"矛盾；要走 A 路线必须先明确采用什么许可（常见做法是代码与数据分开：代码用宽松许可，数据用 ODbL 或 CC BY-SA 之类的 copyleft，商业用途另行授权）。

**在决定 A 之前，这一步绕不过去。**

### 5.2 数据体量对 B2B 买家还不够"可采购"

18 国 / 37 条证据 / 17 国字段规则，一个采购方会问：覆盖多少国、更新频率是什么、SLA 怎么定、schema 会不会变。现在三个问题都答不上来。

要变成可采购，缺的是：覆盖度（往 50+ 国走）、制度化的更新频率（`docs/maintenance/monthly-review.md` 已有月度审查流程，需要变成对外可承诺的东西）、以及一份稳定的 schema 文档。这是 6–12 个月的积累，不是一个季度的事。

## 六、对 B2B 路线最硬的反对意见

OTA 和机票元搜索看起来是天然买家——用户订完票，正需要知道要填哪份表。但他们不会买：

**iVisa 给 OTA 分成，官方 URL 不给任何人分成。** 一个 OTA 在"你还需要办入境手续"的位置链到 iVisa 能拿佣金，链到 `tdac.immigration.go.th` 拿 $0。让他们换成我们的数据 = 让他们主动放弃一条收入。商业上没有动机。

这条反对意见成立，且不可绕过。它把 A 路线的买家清单砍掉一大块，剩下的是**没有中介分成绑定、反而有合规义务的那些**：企业差旅工具、保险公司、银行旅行权益、反欺诈厂商。这批买家更小众、销售周期更长，但动机是真的。

同一条逻辑反过来解释了这个站为什么存在：**整条商业链上，只有中介愿意为流量付钱，官方表单不会。** 这是本站的立站前提，也是它变现困难的根本原因——不是执行问题。

## 七、我们还不知道的

- **AI 引用能不能变现。** 44% 流量来自 ChatGPT，而点击只是被引用次数的一小部分（被引用但未点击的更多，且不可测）。2026 年还没有成熟的 AI 引用分成市场。可操作的推论只有一个：**开始把"AI 引用份额"当资产度量和积累**（`llms.txt` 已上线、Bing 已接入且引用基线为 0、IndexNow 未接）。如果引用授权市场出现，持有一个高频被引的垂直事实库有价值；如果不出现，这些动作本身也在带流量，不亏。
- **16/18 国拿不到任何 AI 引流的原因还没定论。** GSC 报告已排除页面年龄和内容体量，接入 Bing 后测出 Copilot 引用为 0，说明 ChatGPT 走的是 OpenAI 自有索引。扩散机制未知，2–4 周后复看。
- **B2B 数据愿不愿意付费，一次都没验证过。** 上面全部是推理。最便宜的证伪方式是找 3–5 家目标类型的公司直接问，不需要先建 API。

## 八、建议的分层

**现在做（与流量无关、成本近零）**

1. 补 LICENSE，同时修正 `about.md` 的"100% open source"表述——信用缺口，性质等同 Task 04。
2. 把 37 条诈骗域名提交给 PhishTank / APWG / Google Safe Browsing。同时解决外链 = 0 和权威背书，是本文投入产出比最高的一项。
3. 补 `.github/FUNDING.yml`。
4. 补 `data/rules/australia.json` 和 `data/fields/australia.toml`，把 18 国补齐。

**补完承诺（收入不指望）**

5. 接 Airalo，兑现 Task 04 和 `about.md` 的"两个伙伴"。**不改位置**——按第二节，改位置不解决问题。

**积累到阈值再启动（6–12 个月）**

6. 覆盖度往 50+ 国走 + 月度审查制度化 + schema 文档 → 然后才谈 A 路线的 API 和定价。
7. 期间用最便宜的方式证伪需求：找 3–5 家 TMC / 保险 / 风控直接问愿不愿付费，先于任何工程投入。

**永不做**

第四节 D 表全部。

## 九、需要拍板的

1. **是否接受"从 B2C 注意力转向 B2B 数据"这个方向转换。** 这不是数据能自动得出的结论，它意味着未来一年的工作重心从"提升页面转化"移到"扩覆盖度、攒证据、建许可"，而这段时间账面收入仍然是 0。
2. **`data/` 采用什么许可。** 决定了 A 路线可不可行，也决定"开源"这个词在本站语境下具体承诺了什么。
3. **联盟位维持现状还是彻底降级。** 本文的立场是维持现状 + 补齐 Airalo，把它当作诚信叙事的组成部分而不是收入来源，不再为它做任何转化优化。
