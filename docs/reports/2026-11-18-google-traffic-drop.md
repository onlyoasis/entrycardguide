# Google 流量 11-12 起断崖：排查结论（2026-11-18）

- 执行：Claude Code（只读排查，没有改站点代码、平台配置或部署）。
- 数据：`seo-ops` MCP 取 GSC Search Analytics（`sc-domain:entrycardguide.com`，网页搜索，太平洋时间，`dataState=all`，11-16 及以前为定稿）、GSC 网址检查、GA4 Data API（属性 536218791，Asia/Shanghai 时区）、Bing Webmaster；Cloudflare GraphQL（zone 请求日志，按 UA 过滤）；内置浏览器读 Google Search Status Dashboard 与 Safe Browsing 透明度报告；curl 读线上页面。
- 口径：下文“已核”是本次查询直接得到的数字；“推断”是根据数据特征的判断，没有 Google 方面的确认。

## 一、结论

1. **只掉了 Google，Bing 没掉，而且还在涨。** GSC 展示从 11-04～11-11 日均 1,581 次跌到 11-12～11-16 日均 70 次（−96%），点击从日均 26.6 次跌到 2.2 次（−92%）。GA4 里 google/organic 会话同步从日均 28.6 次跌到 3.3 次（−88%），两套独立统计对得上，是真实流量损失，不是报表口径问题（已核）。同期 GA4 的 bing 会话日均 55 → 57，Bing Webmaster 11-16 单日 171 次点击、5,839 次展示，为历史最高（已核）。全站自然搜索会话合计日均 92.5 → 71（−23%）。
2. **时间点与 Google 2026 年 11 月核心更新吻合。** Search Status Dashboard 记录：核心更新 2026-11-10 10:06（太平洋时间）开始推送，“最长 2 周”，截至 11-18 仍未标记完成（已核）。本站 11-11 开始走低，11-12 断崖。
3. **是站点级的整体降权，不是个别页面或技术故障。** 所有页面类型、所有语言、手机和桌面同一天一起掉（见第二节）；页面仍在索引里、抓取成功、robots 允许、规范网址正确；对极长尾的精确匹配词仍排第 1～3 位，但中高量词整批消失（已核）。这种“仍收录、精确词还在、其余全没了”的形态符合核心更新对整站质量的重新评估（推断）。
4. **没有人工处置。** 2026-11-18 用户在内置浏览器登录后查看 GSC 后台：人工处置、安全问题均为“未检测到任何问题”；“移除”页过去 6 个月没有任何请求；网页索引报告已编入索引 1,230、未编入 74（报告更新至 11-13），10 月中以来平稳，没有掉收录（已核）。所以这是算法层面的变化，不是处罚，也没有可以提交的复审。

## 四、为什么偏偏是本站（推断，待推送结束后验证）

核心更新评的是整站，Google 不会告诉具体原因。下面是本站在更新前一个月里出现的、可能拉低整站评价的变化，按可疑程度排：

1. **资料库页占了全站一半以上。** 三语站点地图共 1,245 个网址，其中 `/library/` 723 个（58%），10 月中旬上线，来自目的地数据集，公共投影里大量事项是“部分核实/待核”。这类模板批量页上线后展示增长很快（10-14 起全站展示从约 500/天涨到 1,500/天），也是核心更新最常打击的类型（规模化内容）。
2. **标题自称“官网”。** 11-06、11-08 起 53 国表单页标题改成“官网 + 官方域名”，例如英文 `Thailand Arrival Card (TDAC) Official Website: tdac.immigration.go.th, Free`、中文 `泰国入境卡官网：TDAC 免费填写入口 tdac.immigration.go.th`。这在 Bing 上提升了点击率，但对 Google 来说，第三方站点在政府服务类查询里自称 Official Website，可能被看成误导。这是下跌前最近的一次全站性改动（距下跌 4～6 天）。
3. **三分之一页面是机器转换的繁体重复版。** `/zh-hant/` 由简体经 OpenCC 生成，与简体页内容一一对应。
4. **联盟条大面积铺开。** 11-06 起全站约 477 页的官网链接框下加了联盟条，11-16 才挪到校验器之后（42 页）。

以上没有一条能用现有数据证明，只能在推送结束后看哪些页面恢复、哪些没有，再决定改什么。

## 五、建议

1. **推送期间不要为 Google 做大改。** Google 的建议是推送结束后至少再等一周，再和更新前比较。推送预计 11-24 前后结束，**12-01 之后**再取 GSC 做恢复评估，用 11-04～11-11 作基线。
2. ~~用户登录 GSC 查人工处置和安全问题~~：2026-11-18 已查，均无问题（UA-166 完成）。不需要也无法申请复审，只能靠改进内容后等 Google 下一次重新评估。
3. **暂停按 Google 排名回滚标题的规则。** 原计划 11-20 复测马来西亚、新加坡、韩国标题分工（排名掉 2 位以上就回滚），以及 11-27、12-11 的 SEO 复评 P1 复查，Google 数据现在被核心更新污染，掉排名不能算到标题头上。这几次复测改用 Bing 数据判断；Google 侧一律等 12-01 之后再看。
4. **如果 12-01 后仍未恢复**，按第四节的顺序考虑（每项都要用户决定）：
   - 资料库页：给核实事项少的目的地页加 `noindex`（或移出站点地图），只保留有已核实官方事项的页面被收录；
   - 表单页标题：把“官网 / Official Website”改成“官方网址 / official link”一类不会被理解成自称官方的说法，Bing 已有的点击率收益要一起评估；
   - 繁体页：保留，但考虑只让有实际繁体搜索需求的页面进索引。
5. **短期流量靠 Bing。** Bing 在自然搜索会话里的占比下跌前约六成、现在约八成，而且还在涨，这几周标题与内容的效果评估以 Bing Webmaster 为准。

## 六、限制

- 核心更新的具体原因 Google 不披露，第四节都是推断。
- GSC API 返回的是头部行，按页面类型的拆分是 `contains` 过滤后的合计，不是完整导出。
- Cloudflare 免费版日志是采样的，Googlebot 按 UA 过滤，没有做反查 IP 验证。
- GSC 网页索引报告只更新到 11-13，之后几天的收录数未知（网址检查抽查的 3 页 11-18 仍在索引中）。
