- 公开字段：目的地 ID/中英名称/地区/既有指南映射；事项 ID/名称/类别/机构/官方地址/渠道/费用/适用条件/办理时间/核验日期；对应的公开引用标题、发布方和 URL。页面事实引用继续可追溯。

## 提交与发布保护

- `.gitignore` 是第一层，不能把它说成已经阻止强制加入。
- 提供提交前门禁，检查真实 Git 索引中的 `data/travel_library/`；即使 `git add -f`，也拒绝提交。不得修改或清空已有索引。
- 安装检查前先检查现有 hooks 和 `core.hooksPath`，有自定义配置则保留并明确报告，不能覆盖。当前 canonical 只查到 `.sample` hooks，未配置 `core.hooksPath`，安装前仍须重核。
- GitHub CI 也执行检查，但 CI 发生在上传之后，不能称为首次泄露防线。本地 hooks 可被手动绕过，这个限制必须说明。
- 若增加 pre-push 检查，应检查将上传的提交范围，不能只检查最终工作树；避免中间提交加入后再删除仍泄露历史。不需要为了增加层数而实现复杂 Git 框架。
